# Segurança

Não publique vulnerabilidades, segredos ou dados pessoais em issues públicas.

Para relatar uma vulnerabilidade, utilize o canal privado de segurança do repositório no GitHub. Inclua componente afetado, impacto, forma de reprodução e mitigação sugerida. Não execute testes contra infraestrutura de terceiros.

O conteúdo do projeto é educacional. Antes de aplicar qualquer manifesto em produção, revise imagens, permissões, políticas de rede, armazenamento, limites de recursos e requisitos de conformidade da organização.
